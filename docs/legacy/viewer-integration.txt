  3. JS — Add this function BEFORE the existing showPreview function
================================================================================

  function updateDocViewer(archivoR2) {
    const panel   = document.getElementById('preview-panel');
    const viewer  = document.getElementById('prev-viewer');
    const img     = document.getElementById('prev-viewer-img');
    const pdf     = document.getElementById('prev-viewer-pdf');

    // Reset
    img.style.display = 'none';
    pdf.style.display = 'none';
    img.src = '';
    pdf.src = '';

    if (!archivoR2) {
      viewer.style.display = 'none';
      panel.classList.remove('has-viewer');
      return;
    }

    const src = `${WORKER_URL}/api/soporte/${archivoR2}`;
    const ext = archivoR2.split('.').pop().toLowerCase();
    const isImage = ['jpg','jpeg','png','gif','webp','bmp','tiff','tif'].includes(ext);

    viewer.style.display = 'flex';
    panel.classList.add('has-viewer');

    if (isImage) {
      img.src = src;
      img.style.display = 'block';
    } else {
      // PDF or other document — use iframe
      pdf.src = src;
      pdf.style.display = 'block';
    }
  }

================================================================================
  SUMMARY OF CHANGES
================================================================================

  - CSS adds .has-viewer class that splits preview-body into 2 columns
  - On mobile (<768px) columns stack vertically (viewer on top, fields below)
  - HTML wraps existing fields in .preview-fields-col and adds .preview-viewer
    with an <img> and <iframe> (both hidden by default)
  - JS updateDocViewer() detects image vs PDF by file extension, shows the
    correct element, and sets src to WORKER_URL/api/soporte/{archivo_r2}
  - Image extensions: jpg, jpeg, png, gif, webp, bmp, tiff, tif
  - Everything else (pdf, etc.) renders in an iframe
  - When archivo_r2 is null/empty, the viewer hides and layout returns to
    the original 3-column field grid
  - Uses existing CSS variables: --bg, --border, --accent, --text, etc.
  - WORKER_URL = 'https://cocicp-gastos.ddropero.workers.dev'
