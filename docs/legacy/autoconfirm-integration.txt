SUMMARY OF BEHAVIOR:

- Sidebar gets a new "Opciones" section with a checkbox "Auto-confirmar
  conocidos" persisted in localStorage.

- When the checkbox is on, FormData includes auto_confirm=1.

- Worker POST /api/upload: after building the preview, if auto_confirm=1 AND
  the four safety conditions are met (en_catalogo===true, confianza_global==='alta',
  no duplicate, total>0), it runs the same INSERT as /api/confirm and returns
  {ok:true, preview, auto_confirmado:true, numero}.

- Frontend handleFiles: when data.auto_confirmado is truthy, the pill shows
  "check auto #N filename" instead of the normal check, the preview is NOT
  pushed to previewQueue, and the counter tracks auto-confirmed separately.

- Toast message shows e.g. "3 auto · 2 para revisar" instead of "5 nuevos".

- After all uploads, if any were auto-confirmed, cargarGastos() refreshes the
  table so the new rows appear immediately.

- Fallback: if auto_confirm=1 but conditions are NOT met (unknown provider,
  low confidence, possible duplicate, or negative total), the response is the
  normal preview — goes to the review queue as before.
